# Tony Hawk's Pro Skater 4+

A mod with the goal of modernizing Tony Hawk's Pro Skater 4, giving it sismilar treatment to reTHAWed.

![Logo](https://github.com/user-attachments/assets/d4093c1d-047a-48e6-9f27-20c536c4e051)


## Features

- Properly Scaled Widescreen (Hor+ UI and FOV)
- Proper Controller Support for Xinput, SDL, and Dinput, with matching controller glyphs based on the controller you use.
- Dynamic FPS (Highest tested is 240)
- HD UI and world textures (see notes)
- High defenition soundtrack
- Online Server Connection
- Real D3D8 passthrough (see notes)

## Installation


Installation is super simple. Dowload the .zip file and extract it into your 'THPS4/Game/' folder.  On Wine, you will need to add D3D8.dll as a .dll override.
## Notes

This covers some misc. stuff about the mod.

- If you use dgVoodoo, or another Direct3D 8 wrapper, you MUST rename it to something else. This mod will otherwise overwrite it and may break your game. If you rename it, please specify what it was renamed to under the Compat section of THPS4Plus.ini
- I have remade the entire HUD, that's it. I have done some world textures, but only the really low quality ones.
